# Cakrawala V2 assets

Seluruh aset visual tema Cakrawala disimpan dan dikelola di paket ini.

- `cakrawala-landscape.svg`: ilustrasi panorama pedesaan untuk fallback hero.
- `pattern-leaves.svg`: ornamen dedaunan halus.
- `icon-layanan.svg`: kumpulan ikon garis layanan publik.
- `icon-potensi.svg`: ilustrasi potensi desa.
 
Foto tenant tetap memakai URL media yang tersimpan pada data desa; aset ini hanya fallback dekoratif dan tidak menggantikan konten dinamis tenant.
